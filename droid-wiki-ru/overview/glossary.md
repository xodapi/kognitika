# Глоссарий

## EventBus

Синглтон-эмиттер событий в `src/core/events/event-bus.ts`, развязывающий движки тренажёров от аналитических подписчиков и персистентности. События типизированы через интерфейс `EventMap` и валидируются Zod-схемами перед доставкой. Middleware-цепочки обрабатывают события по порядку.

## Brain ID

Первичная система аутентификации. Пользователь регистрируется по номеру телефона и получает `brainId`, идентифицирующий его без email или пароля. Brain ID токены подписываются JWT и верифицируются серверно. Платформа не раскрывает сырой Brain ID в API-ответах или аналитических экспортах.

## Seed

Целочисленный параметр, передаваемый во все генераторы для детерминированного результата. Одинаковый seed всегда даёт одинаковую сетку, последовательность или набор задач. Гарантирует воспроизводимость тестов.

## Event-Driven Architecture (EDA)

Архитектурный паттерн, где компоненты общаются через события, а не прямые вызовы методов. В Когнитике: движки тренажёров эмитят события в EventBus, а аналитика, персистентность и UI-виджеты реагируют независимо.

## WASM-ready boundary

Контракт границы между аналитическим Worker'ом и остальной системой, в терминах которых будущий Rust/WASM модуль может заменить JS-реализацию. Worker принимает `ClickEvent` объекты (`{ cellId, reactionTimeMs }`) и возвращает формы метрик. WASM-модуль, реализующий этот интерфейс, может подменять JS без изменения другого кода.

## Privacy-safe analytics export

Эндпоинт аналитического экспорта `/api/analytics/export` возвращает когнитивные данные в формате, очищеняет все лично идентифицируемые данные (PII), сырой session ID, точные таймстемпы. Ответ включает объект `privacy` с подтверждением `safe_for_external_llm: true` — данные можно безопасно подавать в любой LLM для персонального анализа.

## Analytics worker

Web Worker в `src/workers/analytics.worker.ts`, вычисляющий когнитивные метрики (распределения времени реакции, точность, индекс усталости, индекс вовлечённости, оценка подозрительных паттернов) из сырых клик-событий. Работает вне UI-треда, не блокируя взаимодействия.

## Cognitive Module Graph

Визуализация всех тренажёров и их пререквизитных связей. Определена в `src/lib/knowledge-base.ts` и рендерится через `@xyflow/react`. Показывает, какие модули пользователь прошёл и какие доступны для разблокировки.

## Express Knowledge Hub

Единый маршрут `/express-knowledge`, объединяющий Ментальную арифметику (задание #7) и Таблицу Шульте 1-90 (задание #8) с карточками режимов, брифингами, нормативами, ежедневными заданиями и кросс-режимовым сравнением прогресса.

## Neurotrainer / Страж Разума

Домен модулей критического мышления: Scanner (Смысловой сканер), Decryptor (Декриптор), Reality Check (Верификация реальности), Noise Reduction (Редукция шума), Hype Filter, Reframing, Rejection Immunity, Storytelling, Deep Focus. Работают с контентом из статической БД (`src/lib/content-db.ts`, 500+ карточек, seed-детерминизм).
