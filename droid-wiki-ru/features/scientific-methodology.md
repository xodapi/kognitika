# Барометр Люшера (Lüscher Color Test)

**Маршрут**: `/luscher` · **Компонент**: `LuscherTest` · **Домен**: Эмоциональное состояние · Стресс-диагностика · Компенсаторное поведение

---

## Что это

**Цветовой тест Макса Люшера (1947)** — проективная методика: **последовательный выбор цвета** раскрывает текущее эмоциональное состояние, уровень стресса, компенсаторные стратегии.

В Когнитике используется как **«барометр»** — быстрая (1–2 мин) проверка эмоционального фона **до** и/или **после** когнитивной тренировки.

---

## Зачем нужен в Когнитике

| Сценарий | Зачем | Что даёт |
|---|---|---|
| **Pre-training** | Замерить базовый эмоциональный фон перед тренировкой | Понять, в каком состоянии пришёл пользователь (стресс, апатия, излишняя возбудимость) |
| **Post-training** | Замерить изменение после тренировки | Оценить эффект тренировки на эмоциональном фоне (например, после N-Back или Диспетчера) |
| **Pre/Post в одном** | Барометр до + тренировка + барометр после | Измерить дельту эмоционального состояния от тренировки |
| **Отдельно** | Самостоятельная диагностика | Быстрый чек-ин: «Как я себя чувствую сейчас?» |

---

## Как работает в Когнитике

### Протокол (упрощённый Люшер)
1. **8 цветов** в случайном порядке (синий, зелёный, красный, жёлтый, фиолетовый, коричневый, чёрный, серый)
2. **Проход 1**: «Выберите цвет, наиболее приятный сейчас» → цвет исчезает → повторять 8 раз
3. **Проход 2**: те же 8 цветов, новый рандомизированный порядок → повторный выбор
4. **Результат**: интерпретация по позициям цветов в ряду предпочтения + сравнение проходов

### Цвета и их психологический смысл (Люшер)

| Цвет | Код | Базовая потребность | Физиология |
|---|---|---|---|
| **Синий** | 1 | Спокойствие, привязанность, удовлетворение | Парасимпатика, ↓ АД |
| **Зелёный** | 2 | Устойчивость, самодостаточность, контроль | Баланс, тонус симпатики |
| **Красный** | 3 | Активность, энергия, завоевание | Симпатика, адреналин, ↑ АД |
| **Жёлтый** | 4 | Ожидание, расширение, свобода, будущее | Лимбическая активация, дофамин |
| **Фиолетовый** | 5 | Магическое мышление, слияние, фантазия | Дезинтеграция границ Эго |
| **Коричневый** | 6 | Телесность, сенсорное удовольствие, отдых | Висцеральная сенсорика |
| **Чёрный** | 7 | Отказ, защита, границы, завершение | Ингибиция, тормозной контроль |
| **Серый** | 8 | Нейтральность, отстранённость, ожидание | Базальный уровень, «пауза» |

## Интерпретация результатов

### Позиции в ряду предпочтения (нормы)

| Цвет | Нормальная позиция | Что значит смещение |
|---|---|---|
| **Синий (1)** | 1–2 | > 3 = дефицит привязанности, тревога |
| **Зелёный (2)** | 1–3 | > 4 = потеря контроля, неадаптивность |
| **Красный (3)** | 2–4 | 1 = гиперактивность/агрессия; 5+ = астения |
| **Жёлтый (4)** | 2–5 | 1 = импульсивность; 6+ = безнадежность |
| **Чёрный (7)** | 7–8 | 1–3 = отказ от реальности, негативизм |
| **Серый (8)** | 7–8 | Ранний = апатия, деперсонализация |

### Коэффициенты Люшера

**Коэффициент стресса (Stress Index)**:
```
Stress = Σ |позиция_проход1 - позиция_проход2| для всех 8 цветов
Norm: 8–14.  >20 = высокий стресс, неадаптивность
```

**Автономия (Autonomy Index)**: позиция Зелёного + позиция Красного. Норма 3–6.

## Как используется в Когнитике

### 1. Pre-Training Barometer (до тренировки)
- Пользователь проходит тест Люшера **перед** стартом модуля (N-Back, Schulte, Dispatcher)
- Результат сохраняется в метаданные сессии (`preLuscherSequence`)
- Даёт контекст: «Пришёл в стрессе / усталости / апатии / оптимальном состоянии»

### 2. Post-Training Barometer (после тренировки)
- После завершения модуля — повторный тест
- Сравнение Pre vs Post показывает **эмоциональный эффект тренировки**

### 3. Pre/Post в одной сессии (опция в UI)
- Некоторые модули (Stroop, N-Back) имеют чекбокс **«Барометр Люшера ДО/ПОСЛЕ»**
- Автоматически: Люшер → Тренировка → Люшер → сохранение обеих последовательностей

## Научная база

- **Люшер М. (1947/1971)** — «Цветовой тест», «Психология цвета»
- Валидация: 2000+ исследований, кросс-культурная устойчивость цветовых предпочтений
- Критика: низкая тест-ретест надежность для диагнозов, **но высокая чувствительность к изменению состояния** (state vs trait) — именно это и используется в Когнитике
- Нейрофизиология: цветовые предпочтения коррелируют с ВНС (парасимпатика/симпатика), уровнем кортизола, дофаминовой системой

## Интеграция в тренировки

| Тренажёр | Опция Люшера | Зачем |
|---|---|---|
| **Stroop** | Чекбокс «Барометр Люшера ДО» | Струп нагружает исполнительный контроль — важно знать базовый стресс |
| **N-Back** | Чекбокс «Барометр Люшера ДО» | N-Back сильно нагружает рабочую память — стресс снижает d-prime |
| **Stroop + Alphabet** | Чекбокс «Барометр Люшера ДО» | Комбинированная нагрузка на тормозной контроль |
| **Отдельно** | `/luscher` | Самостоятельная диагностика в любой момент |

## Результат в метаданных сессии

```json
{
  "gameType": "N_BACK",
  "metadata": {
    "score": 890,
    "preSequence": [1, 3, 2, 4, 6, 5, 8, 7],
    "postSequence": [1, 2, 3, 4, 5, 6, 7, 8],
    "stressMode": false
  }
}
```

- `preSequence` — порядок цветов до тренировки (массив 8 чисел 1–8)
- `postSequence` — порядок после (если включена опция Post)
- В экспорте (`/api/analytics/export`) последовательности включаются в `metadata`
