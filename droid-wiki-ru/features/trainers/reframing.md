# Рефрейминг (Reframing)

**Маршрут**: `/reframing` · **Компонент**: `Reframing` · **Домен**: Когнитивная гибкость + Эмоциональная регуляция + Реаппraisal

---

## Теория

**Когнитивный рефрейминг (Cognitive Reappraisal)** — стратегия эмоциональной регуляции: **переосмысление** ситуации для изменения её эмоционального воздействия, **без отрицания реальности** (Gross, 1998).

**В Когнитике**: тренировка навыка находить **конструктивный ракурс** на негативных событиях.

**3 типа адаптивного рефрейминга**:

| Тип | Суть | Пример |
|---|---|---|
| **Позитивный реаппraisal** | Найти пользу / урок / возможность | «Провал проекта → бесценный опыт для следующего» |
| **Декатастрофизация** | Снизить воспринимаемую угрозу | «Меня уволят → жизнь не кончится, найду лучше» |
| **Перспективное взятие** | Взгляд со стороны / через время | «Через год это покажется мелкой неприятностью» |

**3 типа дезадаптивных ответов (дистракторы)**:

| Тип | Пример | Почему вреден |
|---|---|---|
| **Катастрофизация** | «Всё пропало, жизнь кончена» | Усиливает тревогу, парализует действие |
| **Самообвинение** | «Я ничтожество, всё моя вина» | Депрессивная спираль, снижает агентность |
| **Избегание / Отрицание** | «Проблемы нет, сам пройдёт» | Накопление нерешённых проблем |

---

## Как проходить

1. **Ситуация**: описание негативного события (работа / отношения / здоровье / самооценка)
2. **4 варианта ответа**: 1 оптимальный (один из 3 адаптивных) + 3 дезадаптивных
3. **Задача**: выбрать **лучший рефрейминг**
4. **Фидбек**: почему этот вариант работает + разбор ошибок дистракторов
5. **Сессия**: 10 ситуаций (бытовые → экзистенциальные)

## Метрики

| Метрика | Норматив |
|---|---|
| **Optimal Choice Rate** | > 80% |
| **Error Profile** | Катастрофизация / Самообвинение / Избегание — баланс |
| **Latency** | Ср. время выбора < 15 сек |
| **Consistency** | Стабильность стратегии по сессиям | Высокая |

## Система оценки

- Оптимальный: +100
- Близкий (декатастрофизация вместо позитивного): +50
- Катастрофизация / Самообвинение: −30
- Избегание: −50
- Серия 5 оптимальных подряд: +200 бонус
