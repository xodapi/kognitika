# Таблица Алфавит (Alphabet Table)

**Маршрут**: `/alphabet-table` · **Компонент**: `AlphabetTableTrainer` · **Домен**: Селективное внимание + Сенсомоторная координация + Переключение моторных программ

---

## Теория

**Таблица Алфавит** — адаптация методики «Таблица Шульте» для кириллицы с добавлением **моторного переключения**. Пользователь видит букву и команду (П/Л/О) и должен выполнить соответствующее действие.

**Когнитивные механизмы**:
- **Зрительное распознавание** буквы (визуальная экспертиза)
- **Чтение команды** (П/Л/О) — семантическая обработка
- **Выбор моторной программы** — правая рука / левая рука / обе руки
- **Исполнение** — подавление конкурирующих моторных схем
- **Переключение** между правилами (task switching cost)

**Научная база**: сочетание зрительного поиска (Schulte) + выбор ответа (Choice Reaction Time) + переключение задач (Rogers & Monsell, 1995).

---

## Как проходить

1. **Поза**: сидите прямо, экран на уровне глаз, клавиатура удобно
2. **Экран**: появляется буква + команда (П / Л / О)
3. **Действие**: нажмите соответствующую кнопку максимально быстро и точно
4. **Клавиатура** (рекомендуется):
   - `→` / `D` — **П** (Правая рука)
   - `←` / `A` — **Л** (Левая рука)
   - `Пробел` / `O` — **О** (Обе руки)
5. **Touch**: нажимайте экранные кнопки (П / Л / О)
6. **Каждая буква** встречается не более одного раза за сессию

### Режимы (пресеты)

| Пресет | Описание | Когнитивная нагрузка |
|---|---|---|
| **balanced** | Сбалансированное распределение П/Л/О | Базовая |
| **right-heavy** | Преобладание правой руки | Лateralization |
| **left-heavy** | Преобладание левой руки | Лateralization |
| **switch-heavy** | Частые переключения П↔Л↔О | Высокая (switch cost) |

## Метрики

| Метрика | Что показывает | Норматив |
|---|---|---|
| **Точность** | % верных моторных выборов | > 95% |
| **Ср. реакция** | Скорость сенсомоторной обработки | 400–600 мс |
| **Ошибки** | Провалы контроля / переключения | < 3 |
| **Время** | Общая скорость прохождения | Зависит от кол-ва (27–33 буква) |

---

## Система оценки

- Правильный ответ: +10 очков
- Ошибка: -15 очков
- Бонус за серию > 10: +2/ответ

---

## Типичные ошибки

- **Персеверация**: повтор предыдущего моторного ответа (нажали П вместо Л)
- **Игнорирование команды**: реакция только на букву
- **Замедление на переключениях**: switch cost 100–300 мс после смены П/Л/О
