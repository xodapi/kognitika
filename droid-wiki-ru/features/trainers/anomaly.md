# Детектор аномалий (Anomaly Detector)

**Маршрут**: `/anomaly` · **Компонент**: `AnomalyDetector` · **Домен**: Паттерн-распознавание + Статистическое мышление + Change detection

---

## Теория

**Детектор аномалий** — задача на **выявление нарушений паттерна** в потоке числовых данных в реальном времени. Тренирует:
- **Predictive coding** (Friston, 2010) — мозг как предсказательная машина
- **Statistical process control** (Shewhart, 1931) — контрольные карты
- **Change point detection** — смена режима генерации данных

**Типы аномалий**:

| Тип | Описание | Сложность детекции |
|---|---|---|
| **Point outlier** | Одиночный экстремум | Низкая (Z-score > 3) |
| **Contextual** | Нормально глобально, аномально локально | Средняя (нужен контекст) |
| **Collective** | Последовательность точек аномальна | Высокая (паттерн) |
| **Gradual drift** | Постепенное смещение mean/variance | Очень высокая (накопление) |

---

## Как проходить

1. **Стрим**: точки появляются по одной (скорость 1–2 сек/точка)
2. **Фаза обучения** (первые 15–20 точек): формируется базовая линия (mean, std, trend)
3. **Фаза детекции**: нажимайте «🚨 Аномалия» при подозрении
4. **Фидбек**: мгновенный — зелёный/красный маркер на точке
5. **Сессия**: 60–80 точек, 6–10 аномалий смешанных типов

---

## Метрики

| Метрика | Формула | Норматив |
|---|---|---|
| **Precision** | TP / (TP + FP) | > 80% |
| **Recall (Sensitivity)** | TP / (TP + FN) | > 75% |
| **F1-score** | 2 × P × R / (P + R) | > 0.77 |
| **Latency** | Ср. задержка (точек после аномалии) | < 2 |
| **False Alarm Rate** | FP / (FP + TN) | < 10% |

---

## Система оценки

- TP (своевременно ≤1): +150
- TP (поздно 2–3): +80
- FP: −80
- FN: −60
- Early bird (0 задержка): +50 бонус
- Чистая сессия (FP=0, FN=0): +300
