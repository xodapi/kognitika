# Таблицы Шульте (Schulte Grid)

**Маршрут**: `/schulte` · **Компонент**: `SchulteGrid` · **Домен**: База (Внимание)

---

## Теория

Классическая методика **Schulte tables** (1950s) — золотой стандарт оценки и тренировки:

- **Селективное внимание** — способность фокусироваться на релевантных стимулах, игнорируя отвлекающие
- **Периферическое зрение** — расширение полезного поля зрения без движения глаз
- **Зрительный поиск** — эффективная стратегия сканирования матрицы
- **Тормозной контроль** — подавление импульсивных саккад к ярким/контрастным элементам

**Научная база**: Работа Schulte (1978) показала корреляцию между временем прохождения таблицы и показателями внимания у пилотов, диспетчеров, операторов сложных систем. Норматива для 5×5: 25–35 сек (эксперт), 40–50 сек (хорошо), >60 сек (требует тренировки).

---

## Как проходить

1. **Поза**: сидите прямо, экран на уровне глаз, расстояние 40–50 см
2. **Фиксация взгляда**: зафиксируйте взгляд в центре таблицы (не на конкретной клетке)
3. **Стратегия поиска**: не ищите числа глазами по порядку — используйте периферическое зрение, чтобы «захватывать» сразу 3–5 чисел
4. **Последовательность**: кликайте числа строго по возрастанию (1 → 25)
5. **Ритм**: стабильный темп важнее скорости — избегайте пауз и резких ускорений

### Типичные ошибки
- Движение глаз от клетки к клетке (туннельное зрение)
- Поиск числа «в лоб» вместо периферийного захвата
- Поспешные клики с ошибками (штраф времени > выгода от скорости)

## Режимы (пресеты)

| Пресет | Размер | Особенности |
|---|---|---|
| **Классическая** | 5×5 | Базовый протокол, прямой порядок 1-25 |
| **Обратный** | 5×5 | Порядок 25-1, переключение когнитивной установки |
| **Горбов-Шульте** | 7×7 | Чередование черного/красного: 1 черное → 24 красное → 2 черное → 23 красное... Тест на переключение внимания |
| **Цветовой шум** | 5×5 | Пастельные/контрастные фоны клеток — селективное внимание |
| **Разбросанные карты** | 3-7×3-7 | Случайная геометрия — тренировка адаптивного сканирования |
| **Периферийное расширение** | 6×6 | Расширение поля внимания |
| **Хардкорная инверсия** | 6×5 | Перевернутые/перевёрнутые цифры — максимальная нагрузка на тормозной контроль |

## Pro-режим (Hardcore)

- Лимит времени: **60 секунд**
- Подсказки отключены (текущее число скрыто, показывается «?»)
- Множитель очков: +0.5
- Рекомендация: пауза после 5 минут интенсивной тренировки

---

## Метрики

| Метрика | Что показывает | Норматив (5×5) |
|---|---|---|
| **Общее время** | Скорость обработки + стратегия | 25–35 с (эксперт) → 45 с (новачок) |
| **Ошибки** | Контроль импульсивности | 0 |
| **Стабильность** (SD между кликами) | Ритмичность внимания | < 0.3 с |
| **Время реакции** (мсек/клик) | Скорость решения | 800–1200 мс |

## Система оценки

```
Base Score = max(10, floor(100000 / timeMs))
Multipliers:
- colorNoise ≠ none: +0.2
- distortion: +0.3
- inversion: +0.5
- size > 5: +0.4
- hardcore: +0.5
Final Score = floor(Base Score × Multiplier)
```
