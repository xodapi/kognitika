# Пространственное скрытие (Spatial Concealment)

**Маршрут**: `/spatial` · **Компонент**: `SpatialConcealment` · **Домен**: Пространственная рабочая память + Ментальная ротация + Change Detection

---

## Теория

**Пространственная рабочая память (Spatial WM)** — компонент «эскизного блока» (visuospatial sketchpad) по Baddeley & Hitch. Задача: **запомнить локации** скрытых объектов и **детектировать изменения** при повторном показе.

**Когнитивные механизмы**:
- **Object-file theory** (Kahneman et al., 1992) — временные файлы объектов с координатами
- **Change detection** (Luck & Vogel, 1997) — ёмкость ~3–4 объекта
- **Mental transformation** — ротация/трансляция ментального образа
- **Parietal cortex** (IPS, SPL) — нейронная основа пространственной WM

---

## Как проходить

1. **Фаза кодирования (3 сек)**: на сетке 4×4 / 5×5 появляются **3–6 маркеров** — запомните позиции
2. **Маскировка (500 мс)**: сетка заполняется шумом / очищается
3. **Фаза теста**: одна клетка подсвечивается — **был ли там маркер?**
4. **Ответ**: «Да» / «Нет» (клавиши `Y`/`N` или кнопки)
5. **Фидбек**: зелёный/красный контур клетки
6. **Раундов**: 20, адаптивная сложность (кол-во маркеров 3→6, размер сетки 4→5)

---

## Метрики

| Метрика | Что показывает | Норматив |
|---|---|---|
| **Accuracy** | % верных (Hit + Correct Rejection) | > 85% |
| **d-prime (d')** | Чувствительность (SDT) | > 2.0 |
| **Hit Rate** | % найденных маркеров | > 85% |
| **False Alarm Rate** | % ложных «был» на пустых | < 10% |
| **Mean RT** | Скорость доступа к пространственному образу | < 800 мс |
| **Capacity (K)** | d' × Set Size / 2 (Luck & Vogel) | 3.0–4.0 |

## Система оценки

- Hit: +50
- Correct Rejection: +30
- Miss: −40
- False Alarm: −50
- Бонус за идеальный раунд (5/5): +100
