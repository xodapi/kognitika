# Редукция шума (Noise Reduction)

**Маршрут**: `/noise` · **Компонент**: `NoiseReduction` · **Домен**: Селективное внимание + Signal/Noise дискриминация

---

## Теория

**Редукция шума** — адаптивная задача на выделение целевого сигнала из **прогрессивно зашумлённого** визуального дисплея. Модель: **Signal Detection Theory (SDT)** + **Visual Search** под нагрузкой.

**Когнитивные механизмы**:
- **Feature integration theory** (Treisman) — предварительная обработка признаков
- **Guided search** — топ-дауном توجيه внимания к целевым признакам
- **Perceptual load theory** (Lavie) — высокий перцептивный нагрузка снижает дистракторы

**Научная база**:
- Green & Swets (1966) — Signal Detection Theory
- Wolfe (1994) — Guided Search 2.0
- Lavie (1995) — Perceptual load as a necessary condition for selective attention

---

## Как проходить

1. **Дисплей**: сетка элементов (цвет/форма/ориентация), целевой — **красный вертикальный бар**
2. **Задача**: нажать «Есть цель» / «Нет цели» за лимит времени
3. **Уровни шума** (адаптивные):
   - Уровень 0: чистый фон, 1 цель
   - Уровень 1: 10% дистракторов (похожие по цвету/форме)
   - Уровень 2: 30% дистракторов + динамический шум (мигание)
   - Уровень 3: 50% дистракторов + перекрытие + motion noise
   - Уровень 4: 70% + низкий контраст цели
4. **Адаптация**: 2-up / 1-down staircase → оценка порога (d-prime = 1.5)

---

## Метрики

| Метрика | Что показывает | Норматив |
|---|---|---|
| **Threshold (d')** | Чувствительность на пороге 75% | d' > 2.0 |
| **Hit Rate** | % найденных целей | > 85% на пороге |
| **False Alarm Rate** | % ложных «цель есть» | < 10% |
| **c (Criterion)** | Смещение решения (либеральный/консервативный) | -0.2 < c < 0.2 |
| **RT на пороге** | Скорость обработки при высоком шуме | < 1200 мс |

---

## Система оценки

- База: `1000 × d'`
- Бонус за низкий FA: `+200 × (1 - FA_rate)`
- Штраф за смещение: `-150 × |c|`
