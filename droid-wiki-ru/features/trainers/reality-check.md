# Верификация реальности (Reality Check)

**Маршрут**: `/reality` · **Компонент**: `RealityCheck` · **Домен**: Детекция галлюцинаций AI + Cross-верификация + Эпистемическая бдительность

---

## Теория

**Reality Check** — тренировка **эпистемической бдительности**: способность выявлять **сфабрикованные, искажённые или непроверяемые** утверждения в LLM-контенте и интернете.

**Таксономия галлюцинаций** (Ji et al., 2023):

| Тип | Описание | Детекция |
|---|---|---|
| **Entity fabrication** | Несуществующие люди, книги, компании | Поиск в базах (Wikidata, ISBN, ORCID) |
| **Citation fabrication** | Фейковые DOI, арXiv, PMID | Crossref, PubMed, arXiv API |
| **Numeric hallucination** | Вымышленные статистики, даты, цены | Официальные источники (Rosstat, SEC, ЦБ) |
| **Logical inconsistency** | Внутренние противоречия текста | Семантический парсинг |
| **Attribution error** | Ложная авторство / цитата | Первоисточники (Google Books, Scholar) |
| **Geographic/temporal** | Несуществующие места, смешанные эпохи | GIS, хронологии |

---

## Как проходить

1. **Фрагмент**: 3–5 утверждений (смесь фактов + галлюцинаций)
2. **Для каждого**: вердикт + уверенность + обоснование
   - ✅ **Факт** — подтверждаемо первичным источником
   - ❌ **Галлюцинация** — сфабриковано, ложно
   - ⚠️ **Искажение** — ядро истины + ошибка деталей
   - ❓ **Неверифицируемо** — мнение / прогноз / нет доступа к источнику
3. **Инструменты** (в интерфейсе):
   - 🔍 **Поиск** — мгновенный запрос к поисковику
   - 📚 **Источник** — показать Claimed Source (может быть фейковым DOI)
4. **Фидбек**: Ground Truth + пошаговый разбор + калибровка уверенности

---

## Метрики

| Метрика | Норматив |
|---|---|
| **Detection Rate (Recall)** | > 80% |
| **False Alarm Rate** | < 10% (факты не помечать галлюцинациями) |
| **Precision** | > 75% |
| **Calibration Error** | \|Confidence − Accuracy\| < 0.15 |
| **Source Check Usage** | % утверждений, где использовали поиск | > 60% |

---

## Система оценки

- Вердикт верный: +150
- Категория верная (тип галлюцинации): +50
- Использован поиск + вердикт верный: +30
- FP (Факт → Галлюцинация): −100
- FN (Галлюцинация → Факт): −150
- Идеальный фрагмент (5/5): +300
