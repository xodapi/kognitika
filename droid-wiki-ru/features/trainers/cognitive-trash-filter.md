# Когнитивный мусорный фильтр (Cognitive Trash Filter)

**Маршрут**: `/filter` · **Компонент**: `CognitiveTrashFilter` · **Домен**: Критическое мышление + Фактуральная база + CBT-основы

---

## Теория

**Когнитивный мусорный фильтр** — задача на **разделение объективных фактов и когнитивных искажений** (cognitive distortions). Базируется на **CBT (Cognitive Behavioral Therapy)** таксономии А. Бека и Д. Бернса.

**12 основных искажений** (Burns, 1980):

| Искажение | Суть | Пример |
|---|---|---|
| **Все-или-ничего** | Чёрно-белое мышление | «Если не идеально — то провал» |
| **Сверхобобщение** | Один случай → всегда | «Я опоздал раз → я безнадежно непунктуален» |
| **Ментальный фильтр** | Фокус только на негативе | 9 похвал + 1 критика = «меня ненавидят» |
| **Обнищание позитива** | «Это не считается» | «Сдал экзамен? Ну, повезло, легко было» |
| **Передёргивание выводов** | Чтение мыслей / катастрофизация | «Он не ответил → я ему не нравлюсь» |
| **Катастрофизация** | Максимально плохой исход | «Ошибка в отчёте → уволят → конец жизни» |
| **Эмоциональное обоснование** | Чувство = факт | «Чувствую себя некомпетентным → я некомпетентен» |
| **Долженствование** | Жёсткие правила «должен» | «Я всегда должен быть продуктивным» |
| **Навешивание ярлыков** | Глобальные оценки личности | «Ошибся → я идиот» |
| **Персонализация** | Вина за внешние события | «Она грустная → это из-за меня» |
| **Контрольные заблуждения** | Внешний / внутренний контроль | «Всё зависит от меня» / «Ничего не зависит» |
| **Справедливость** | Мир должен быть справедливым | «Я старался → должно получиться» |

---

## Как проходить

1. **Утверждение**: 1 предложение (мысль / ситуация)
2. **Выбор**: 2 кнопки — **🟢 Факт** / **🔴 Искажение**
3. **Фидбек**: если Искажение — показывается **тип** + **переформулировка** (balanced thought)
4. **Сессия**: 10 утверждений (рандомизировано из пула 50+)

## Метрики

| Метрика | Норматив |
|---|---|
| **Classification Accuracy** | > 85% |
| **Distortion ID Accuracy** | % верных типов среди найденных > 70% |
| **Calibration (Brier)** | < 0.20 |
| **Self-Reference Detection** | Личные утверждения (я/мне/мой) распознаются лучше | Baseline + 15% |

## Система оценки

- Верный класс: +100
- Верный тип искажения: +50
- Калиброванная уверенность (|conf−acc|<0.1): +30
- Ложное срабатывание (Факт → Искажение): −80
- Пропуск искажения: −100
- Идеальная сессия (10/10): +200
