# Струп + Алфавит (Stroop Alphabet)

**Маршрут**: `/stroop-alphabet` · **Компонент**: `StroopAlphabetTrainer` · **Домен**: Тормозной контроль + Переключение задач + Сенсомоторная координация

---

## Теория

**Двухшаговая парадигма**: конфликт смысла/цвета (классический Струп) + управляемое переключение моторного правила (Алфавит).

1. **Фаза 1 — Цвет**: слово написано цветом, не совпадающим со смыслом. Выберите **фактический цвет текста** (подавление авточтения).
2. **Фаза 2 — Команда**: появится команда П/Л/О. Выполните моторное действие (как в Таблице Алфавит).

**Когнитивные механизмы**:
- **Струп-эффект**: конфликт автоматического чтения и контролируемого распознавания цвета
- **Переключение задач**: цвет → команда (task switch cost)
- **Моторный выбор**: П/Л/О (как в Таблице Алфавит)
- **Рабочая память**: удержание правила на 2 шага

**Научная база**: Stroop (1935) + Rogers & Monsell (1995) + алфавитная таблица. Комбинация усиливает исполнительный контроль.

---

## Как проходить

1. **Экран**: слово (например, «КРАСНЫЙ») написано синим цветом + команда «П»
2. **Шаг 1**: нажмите кнопку цвета **СИНИЙ** (1-4 или тач)
3. **Шаг 2**: нажмите **П** (→ / D / правая кнопка)
4. **Повторяйте** для каждого стимула (9–33 стимула)

### Клавиатура

**Цвета** (1-4):
- `1` / `Й` / `Q` — Красный
- `2` / `Ц` / `W` — Синий  
- `3` / `У` / `E` — Зелёный
- `4` / `К` / `R` — Жёлтый

**Команды** (Фаза 2):
- `→` / `D` — П (Правая)
- `←` / `A` — Л (Левая)
- `Пробел` / `O` — О (Обе)

## Метрики

| Метрика | Что показывает | Норматив |
|---|---|---|
| **Ошибки цвета** | Тормозной контроль (подавление чтения) | 0–1 |
| **Ошибки П/Л/О** | Сенсомоторная координация / переключение | 0–2 |
| **Ср. реакция** | Скорость двухшаговой обработки | 800–1200 мс (сумма 2 шагов) |
| **Точность** | Общий исполнительный контроль | > 90% |

---

## Система оценки

- Верный цвет + верная команда: +20
- Ошибка цвета: -10
- Ошибка команды: -10
- Обе ошибки: -25

---

## Типичные ошибки

- **Чтение слова**: нажали «КРАСНЫЙ» вместо цвета текста
- **Персеверация цвета**: повтор цвета предыдущего стимула
- **Смешение фаз**: нажали команду на фазе цвета или наоборот
- **Замедление на switch**: переход цвет → команда стоит 150–300 мс
