# Эффект Струпа (Stroop Test)

**Маршрут**: `/stroop` · **Компонент**: `StroopTest` (ClassicStroopTest) · **Домен**: Селективное внимание, Тормозной контроль, Когнитивная гибкость

---

## Теория

**Классический тест Струпа** (1935) — золотой стандарт оценки исполнительного контроля. Конфликт между **автоматическим чтением** слова и **контролируемым распознаванием** цвета текста.

**Парадигма**:
- Конгруэнтные: слово «КРАСНЫЙ» написано красным → легко
- Инконгруэнтные: слово «КРАСНЫЙ» написано синим → конфликт
- Нейтральные: «XXXX» написано синим → база

**Когнитивные механизмы**:
- **Автоматизация**: чтение — высокоавтоматизированный навык
- **Ингибирование**: подавление доминирующего ответа (чтение)
- **Селективное внимание**: фокус на нерелевантном измерении (цвет)
- **Контроль конфликта**: ACC (передняя поясная извилина) детектирует конфликт

**Научная база**: Stroop (1935), MacLeod (1991) — мета-анализ 400+ исследований. Интерференция = разница RT инконгруэнтных − конгруэнтных.

---

## Как проходить

1. **Экран**: слово-цвет (КРАСНЫЙ, СИНИЙ, ЗЕЛЁНЫЙ, ЖЁЛТЫЙ) в цветном тексте
2. **Задача**: выберите **цвет текста**, игнорируя смысл слова
3. **Время**: 60 секунд, максимальное количество стимулов
4. **Клавиатура** (рекомендуется):
   - `1` / `Й` / `Q` — Красный
   - `2` / `Ц` / `W` — Синий
   - `3` / `У` / `E` — Зелёный
   - `4` / `К` / `R` — Жёлтый

### Режимы

| Режим | Описание |
|---|---|
| **Базовый** | Классический Струп, 60 сек |
| **Люшер (Pre/Post)** | Цветовой тест Люшера ДО и ПОСЛЕ Струпа — эмоциональный барометр |
| **Стресс-инокуляция** | Визуальные/аудио помехи при ошибках — стрессоустойчивость |

## Метрики

| Метрика | Что показывает | Норматив (60 сек) |
|---|---|---|
| **Счёт** | Правильных ответов | 60–80 |
| **Ошибки** | Провалы тормозного контроля | 0–3 |
| **Ср. реакция** | Скорость разрешения конфликта | 600–900 мс |
| **Интерференция** | RT инконгруэнтных − RT конгруэнтных | 100–200 мс |

---

## Система оценки

- Правильный: +10
- Ошибка: -5
- Бонус за серию > 10: +2/ответ

---

## Типичные ошибки

- **Чтение слова**: нажали значение слова, не цвет
- **Замедление**: пауза после ошибки (post-error slowing)
- **Импульсивность**: быстрые ошибки подряд (< 300 мс)
