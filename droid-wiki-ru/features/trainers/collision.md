# Детектор коллизий (Collision Detector)

**Маршрут**: `/collision` · **Компонент**: `CollisionDetector` · **Домен**: Логический анализ + Семантический фильтр + Детекция конфликтов

---

## Теория

**Детектор коллизий** — задача на выявление **логических несовместимостей** в наборе утверждений. Тренирует способность находить внутренние противоречия, циклические зависимости и нарушения аксиом.

**Типы коллизий**:

| Тип | Описание | Пример |
|---|---|---|
| **Прямое противоречие** | A и ¬A одновременно | «Проект готов» + «Проект не готов» |
| **Циклическая зависимость** | A→B→C→A | «A требует B, B требует C, C требует A» |
| **Нарушение транзитивности** | A>B, B>C, но C>A | Приоритеты задач |
| **Ресурсный конфликт** | Σ(требуемые ресурсы) > доступно | «3 задачи по 8ч в 8ч рабочего дня» |
| **Временная коллизия** | Два события в одно время на одном ресурсе | «Встреча в 14:00» + «Звонок в 14:00» |
| **Логическая несовместимость правил** | Правило 1 → X, Правило 2 → ¬X | «Все отчёты в PDF» + «Отчёт №5 только в Excel» |

---

## Как проходить

1. **Набор утверждений**: 4–6 карточек (факты, правила, ограничения, требования)
2. **Задача**: найдите **все** пары/группы коллизирующих элементов
3. **Интерфейс**: клик по первому → клик по второму = выделение коллизии
4. **Подтверждение**: кнопка «Готово» → анализ
5. **Фидбек**: подсветка найденных / пропущенных / ложных + объяснение логики
6. **Сложность**: коллизий 1–3 на набор, типы смешаны

---

## Метрики

| Метрика | Что показывает | Норматив |
|---|---|---|
| **Detection Rate (Recall)** | % реальных коллизий найдено | > 85% |
| **Precision** | % выделенных — реальные коллизии | > 80% |
| **F1-score** | Гармоническое среднее | > 0.82 |
| **False Positive Rate** | Ложные коллизии / все пары | < 10% |
| **Time per Set** | Скорость логического анализа | 20–40 сек |

---

## Система оценки

- Найдена реальная коллизия: +150
- Правильно определено «коллизий нет»: +50
- Ложная коллизия (FP): −80
- Пропуск коллизии (FN): −120
- Бонус за «чистый» набор (0 FP, 0 FN): +200
