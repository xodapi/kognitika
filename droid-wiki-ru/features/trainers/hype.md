# Hype Filter (Фактчек или Хайп)

**Маршрут**: `/hype` · **Компонент**: `HypeFilter` · **Домен**: Критическое мышление + Signal/Noise в убеждающих текстах

---

## Теория

**Hype Filter** — дискриминация **сигнал / шум** в маркетинговых, новостных, питч-текстах. Выявление **преувеличений**, **манипуляций**, **неподкреплённых утверждений**.

**4 класса классификации**:

| Класс | Определение | Маркеры |
|---|---|---|
| **🟢 Твёрдый факт (Fact)** | Проверяемо, точно, первичный источник | Конкретные цифры, ссылка на 10-Q, DOI, закон |
| **🔵 Логическая ошибка (Fallacy)** | Нарушение правил вывода | Post hoc, False cause, Hasty generalization, Ad hominem |
| **🔴 Манипуляция страхом (Fear)** | Угроза без доказательной базы | «Если не X — катастрофа», FUD, urgency без данных |
| **🟡 Кликбейт (Clickbait)** | Сенсационный заголовок, слабое содержание | «Учёные в шоке», «Секрет, который скрывают», цифры без контекста |

---

## Как проходить

1. **Утверждение**: 1–3 предложения (маркетинг / новости / питч / пост)
2. **Выбор**: 4 кнопки — Fact / Fallacy / Fear / Clickbait
3. **Фидбек**: объяснение + маркеры класса
4. **Сессия**: 20 утверждений, адаптивная сложность

---

## Метрики

| Метрика | Норматив |
|---|---|
| **Overall Accuracy** | > 85% |
| **Fact Precision** | Факты не помечать хайпом > 90% |
| **Hype Recall** | Находить Fallacy+Fear+Clickbait > 80% |
| **Calibration Error** | \|Confidence − Accuracy\| < 0.15 |
| **Latency** | Ср. время решения < 10 сек |

---

## Система оценки

- Верно: +100
- Факт → Хайп (FP): −80 (переосторожность)
- Хайп → Факт (FN): −120 (пропуск угрозы)
- Переуверенность (conf>90%, wrong): −50
- 20/20 идеально: +300
