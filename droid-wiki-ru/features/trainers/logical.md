# Логическая матрица (Logical Matrix)

**Маршрут**: `/logical` · **Компонент**: `LogicalMatrix` · **Домен**: Абстрактное рассуждение + Выявление правил + Паттерн-комплишн

---

## Теория

**Логическая матрица** — адаптация **Прогрессивных матриц Равена** (Raven's Progressive Matrices, 1936): выявление правила в сетке 3×3 и выбор недостающего элемента из 6–8 вариантов. Чистая мера **fluid intelligence (Gf)**.

**Типы правил** (систематизировано Carpenter et al., 1990):

| Класс правила | Описание | Пример |
|---|---|---|
| **Постоянство** | Один атрибут не меняется | Форма одинакова во всех ячейках |
| **Квантитативное изменение** | Атрибут меняется на шаг | 1→2→3 фигуры в строке |
| **Качественное чередование** | Атрибут чередуется по правилу | Круг → Квадрат → Круг → Квадрат |
| **Распределение** | Атрибут распределяется по ячейкам | 3 цвета распределены 3×3 |
| **Операция над множествами** | Union / Intersection / Difference | Строка 3 = Строка 1 ∪ Строка 2 |
| **Симметрия/Отражение** | Горизонтальная / вертикальная / диагональная | Зеркальное отражение |
| **Ротация** | Поворот на 90°/180° по строкам/столбцам | Фигура поворачивается по часовой |

**Научная база**:
- Raven (1938/1998) — Progressive Matrices
- Carpenter, Just, Shell (1990) — What one intelligence test measures
- Kovacs & Conway (2016) — Process overlap theory of Gf

---

## Как проходить

1. **Матрица 3×3**: 8 заполненных ячеек, 1 пустая (правый нижний угол)
2. **Варианты**: 6–8 карточек внизу
3. **Стратегия**:
   - Анализируйте **по строкам** и **по столбцам** параллельно
   - Ищите **инварианты** (что не меняется)
   - Проверяйте **операции**: сложение, вычитание, XOR, наложение
   - Исключайте варианты, нарушающие найденные правила
4. **Время**: 60 сек на матрицу (адаптивно)
5. **Сессия**: 10–12 матриц, прогрессивная сложность
