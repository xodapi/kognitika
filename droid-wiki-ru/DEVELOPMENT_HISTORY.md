## Фаза 0: Фундамент (Май–Июнь 2026)

### Базовая инфраструктура
- **Монорепо** с pnpm workspace (`apps/`, `packages/`, `crates/`)
- **React + Vite + TypeScript** frontend архитектура
- **Express + Socket.io** бэкенд с Prisma ORM
- **PostgreSQL 15** как основное хранилище

## Фаза 3: Express Knowledge Hub (Июль 2026)

### Мотивация
Объединить **Задание №7 (Mental Math)** и **Задание №8 (Schulte Table 90)** в единый хаб "Экспресс-знания" по продуктовому спек. Без LLM интеграции в этой фазе (явный запрос пользователя: "пока без llm").

### Реализация
**Новый компонент:** `ExpressKnowledgeHub.tsx` (591 строка)

```
┌─────────────────────────────────────────────────────┐
│  Express Knowledge Hub                              │
├─────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌────────────────────────┐  │
│  │  Mental Math     │  │  Schulte Table 90      │  │
│  │  [Stats Card]    │  │  [Stats Card]          │  │
│  │  [Briefing ▼]    │  │  [Briefing ▼]          │  │
│  └──────────────────┘  └────────────────────────┘  │
├─────────────────────────────────────────────────────┤
│  Daily Task XP Preview  │  Cross-Mode Comparison   │
├─────────────────────────────────────────────────────┤
│  Quick Links: N-Back • Stroop • Spatial • Wiki      │
└─────────────────────────────────────────────────────┘
```

### Реализованные фичи
1. **Карточки режимов** — Живая статистика из `/api/progress` (лучшее время, счёт, точность, сессии)
2. **Модалки брифинга** — Алгоритмы, пресеты/правила, нормативы для каждого режима
3. **Интеграция ежедневных задач** — Превью XP из `/api/dashboard/status`
4. **Cross-mode сравнение** — Сетка метрик рядом
5. **Быстрые ссылки** — Прямая навигация к связанным Base модулям
6. **Тактильная обратная связь** — `useHaptics` на клики карточек, открытие брифингов
7. **Адаптивность** — Mobile-first, работает на всех брейкпоинтах

### Точки интеграции
- **Маршрут:** `/express-knowledge` (добавлен в `APP_ROUTE_PATHS`)
- **Навигация:** Header (иконка Zap), Mobile nav, Bottom nav
- **Иконки:** `Zap` из Lucide React
- **База знаний:** Статьи для `mental-math` и `schulte-90` уже существуют

### Коммиты
- Реализация Express Knowledge Hub (недавний, ещё не в логе выше)
- Регистрация маршрута в `route-config.tsx`
- Ленивый импорт в `App.tsx`
- Фиксы тестов для асинхрендренринга Dashboard UI

## Уроки

1. **Контрактные тесты предотвращают дрифт** — Контракт навигации сразу ловит потерянные маршруты
2. **Асинхронные паттерны тестов важны** — `waitFor` устраняет флаки UI тестов
3. **Тактильная обратная связь дешёвая но эффективная** — 50 строк хука, заметный UX win
4. **Skeleton loaders > спиннеры** — Измеримое улучшение воспринимаемой производительности
5. **Repository-first deploy работает** — 0 production drift с момента принятия
6. **Нет Firebase = проще ops** — Brain ID + Prisma + PG достаточно
