## Архитектурные решения (недавние)

1. **Никакого Firebase в рантайме** — только Brain ID + Prisma + PostgreSQL (по AGENTS.md)
2. **Repository-first deploy** — никаких прямых патчей в прод
3. **Event-driven frontend** — React + Vite + Motion, не Next.js
4. **pnpm workspace** — Монорепо с shared пакетами
5. **Vitest для тестов** — Нет Jest, нативная ESM поддержка
